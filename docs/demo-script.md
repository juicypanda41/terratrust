# 2:40 Demo Script

Use this as a timed structure, then record the actual duration and every team member’s contribution in `docs/demo-rehearsal-record.md`.

## 0:00-0:20 - Problem

“Satellite imagery can support ecosystem monitoring, but a classifier that produces an answer for every image can create dangerous false confidence.”

## 0:20-0:35 - Solution

“TerraTrust classifies clear land-cover scenes automatically and sends uncertain scenes to people instead of guessing.”

## 0:35-1:25 - Product

Open **Analyze**. Show the clear forest scene being accepted, then the ambiguous highway scene being routed to **Human verification**. Explain the two-check policy in one sentence.

## 1:25-1:55 - Evidence

Open **Validation**. Show the target/result table first: 89.4% always-predict accuracy, 91.4% accepted-case accuracy at 78.9% coverage, calibration error reduced to 0.87%, and p95 local CPU latency of 22.3 ms. State that all final metrics use the held-out 4,050-scene test split.

## 1:55-2:15 - SDG and impact

Show the three-step contribution chain and connect the screening workflow to SDG Targets 15.1 and 15.2. State that current evidence measures reliability and potential verification-workload reduction—not conservation outcomes.

## 2:15-2:30 - Scale and limits

Show the deployment path. Explain that the throughput number is a measured-latency-derived planning estimate, not hosted capacity. State the current European scene-classification boundary and the need for spatial validation.

## 2:30-2:40 - Close

“TerraTrust measures when AI is dependable, exposes when it is not, and directs human attention to the satellite images that need it most.”
