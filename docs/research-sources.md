# Research and Source Register

| Claim supported | Source | Use | Limitation |
|---|---|---|---|
| EuroSAT contains 27,000 labeled, georeferenced Sentinel-2 images across ten classes and 13 bands | Helber et al., https://arxiv.org/abs/1709.00029 | Dataset and benchmark context | Original benchmark does not establish modern geographic transfer |
| Official RGB and 13-band archives, file sizes, and checksums | Zenodo, https://zenodo.org/records/7711810 | Provenance and reproducibility | Users must review Sentinel data terms |
| Sentinel-2 supports land-cover and forest monitoring | ESA, https://www.esa.int/Applications/Observing_the_Earth/Copernicus/Sentinel-2/Changing_lands | Real-world problem framing | Mission capability does not validate TerraTrust itself |
| SDG 15.1 concerns terrestrial/inland ecosystems; 15.2 concerns sustainable forest management and deforestation | UN DESA, https://sdgs.un.org/goals/goal15 | SDG alignment | Prototype screening metrics are not SDG outcome indicators |
| Live hackathon criteria and submission requirements | https://ourplanetrocks.devpost.com/ | Eligibility and deliverables | Official WhatsApp/form announcements can supersede page text |
